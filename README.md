# Web Programming Lab - Coffee Counter and Study Vibes

Two beginner JavaScript exercises showing how HTML and JavaScript respond to user input.

## Pages
- `order.html` - choose a coffee/tea drink, enter a name and interact with a sample receipt
- `vibe.html` - choose Focus, Chill or Night Owl to change the page's appearance

## Concepts practiced
- Radio buttons, text fields and button events
- `getElementById`, `getElementsByClassName`, and event listeners
- `switch` / `if` statements
- Updating text and CSS using JavaScript

## Run
Download the repository and open either HTML file in a browser. Everything runs on the client side; no server is needed.

This is a learning demonstration rather than a real café ordering service.
